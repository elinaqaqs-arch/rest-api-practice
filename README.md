# REST API для тренировки

Локальный сервер для тренировки REST-запросов в Postman: методы, коды ответов, заголовки, тело запроса, границы полей и права доступа.

Сервер слушает только `127.0.0.1` и наружу не открыт.

## Запуск

```bash
python3 server.py
```

Первый запрос: `GET http://127.0.0.1:8080/`

В ответе есть список упражнений. Коллекцию в Postman лучше собрать самой: это часть тренировки.

## Токены

Чтение открыто. Изменения требуют заголовок `Authorization`.

| Роль | Заголовок | Что может |
| --- | --- | --- |
| student | `Authorization: Bearer student-token` | создавать и менять |
| mentor | `Authorization: Bearer mentor-token` | то же самое, и еще удалять |

`POST /reset` возвращает три стартовых товара: Notebook, Pen и Lamp.
